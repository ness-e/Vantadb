## Digest internet (≤500 palabras)
- **cargo-modules** (regexident, https://github.com/regexident/cargo-modules): plugin cargo que muestra árbol de módulos y grafo de dependencias; `cargo modules dependencies --lib --acyclic` falla si hay ciclo (un target por vez: `--lib`/`--bin`/`-p`; flags `--features`/`--cfg-test` cambian el grafo — documentar alcance). v0.27 vigente.
- **cargo-coupling** (nwiizo, https://github.com/nwiizo/cargo-coupling, crates.io 0.4.0): mide "right distance" con marco Khononov (Balancing Coupling in Software Design): Integration Strength (Intrusive 1.0 / Functional 0.75 / Model 0.50 / Contract 0.25) × Distance (same-module 0.25 / different 0.50 / external 1.00) × Volatility (git history 0-2 low / 3-10 med / 11+ high); fórmula `BALANCE = (STRENGTH XOR DISTANCE) OR NOT VOLATILITY`. Gates CI: `--check --max-deps/--max-dependents`, `--baseline <ref>` ratchet (solo falla en issues nuevos), `--json`/`--ai` para agentes, `--no-git` sin volatilidad. Experimental: thresholds sujetos a cambio.
- **rust-dsm** (dave-hillier, https://github.com/dave-hillier/rust-dsm, HEAD 5950a18): CLI Node puro tree-sitter (sin Cargo/rust-analyzer): parse → resolve mods → extract símbolos → grafo → Tarjan + Ca/Ce/I=Ce/(Ca+Ce)/A/D → HTML interactivo (D3) o JSON (`-f json`). Soporta `--workspace`. Inmaduro (9 commits, 0★/0 forks) → termómetro informativo, nunca gate bloqueante.
