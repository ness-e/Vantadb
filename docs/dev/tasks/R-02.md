### Causa raíz (hipótesis (a) CONFIRMADA, (b)/(c) descartadas como causa)

1. `RELEASE Automated` (release-plz) corrió sobre el push de `9dbebd18` (run 35531282108, 19:07 UTC) y a las **19:19:08Z creó tag + Release `vantadb-v0.6.0` como `github-actions[bot]`** vía `GITHUB_TOKEN` (tag objeto `c14aa407` idéntico en `origin` — `git ls-remote` — o sea, el tag SÍ está bien publicado).
2. Documentación oficial GitHub (verificada): *"events triggered by the `GITHUB_TOKEN` will not create a new workflow run… if a workflow run pushes code using `GITHUB_TOKEN`, a new workflow will not run even when [a workflow is] configured to run when `push` events occur"* — https://docs.github.com/en/actions/using-workflows/triggering-a-workflow#triggering-a-workflow-from-a-workflow
3. Resultado: el `push tags v*.*.*` nunca materializó un run → `publish-pypi` jamás evaluó su `if:` → `vantadb-py` sigue en 0.5.0 en PyPI (dato del contrato).
4. Contraste que cierra el diagnóstico: `v0.5.0` fue tageado por humano (`tagger=Eros Nessy`) y SÍ produjo 3 push-runs (incl. success). Cambio de variable único = identidad del tagger.
5. (b) descartada como causa: `pypi`/`testpypi` tienen `required_reviewers`, pero eso **pausa** runs (approval), no impide su creación — no hay run que pausar.
6. (c) descartada como causa: el `if: startsWith(github.ref,'refs/tags/v')` nunca se evaluó (sin run); pero **condiciona la vía de salida** (ver abajo).

### Digest internet (≤500 palabras — 2 fuentes oficiales, ambas verificadas vía webfetch)

- GitHub, *Triggering a workflow*: pushes/tags creados con `GITHUB_TOKEN` no generan runs (anti-recursión). Excepciones: `workflow_dispatch` y `repository_dispatch` (siempre generan). Para disparar workflows desde workflows: usar GitHub App token o PAT. URL arriba.
- GitHub, *Contexts reference* (`github` context): `github.ref` = fully-formed ref del branch/tag que disparó el run; para tags `refs/tags/<name>`; vale también para "other triggers" (incl. dispatch con `--ref <tag>`). Implicancia: `gh workflow run … --ref v0.6.0` fija `github.ref=refs/tags/v0.6.0` y satisface el `if:` de `publish-pypi`/`verify-pypi-install`. URL: https://docs.github.com/en/actions/reference/workflows-and-actions/contexts#github-context
