- **FREEZE develop (2026-09-22):** ni un push más a `develop` hasta cerrar Wave B —
  cada push invalida los PRs (strict up-to-date) y re-dispara la tormenta de caché 429.

- **Gate P:** este plan es SOLO análisis+propuesta; cada merge/cierre/rebase se ejecuta
  en `/pipeline run` con verify mecánico por PR (checks verdes + mergeable + diff acotado).

- **Appetite / Branch / Commit:** 2d / según PR (no se commitea en este repo por estos tasks;
  los merges son botones `gh pr merge` con `--squash` o `--merge` según tamaño).
