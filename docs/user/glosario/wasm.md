# WASM

## Definition

Portable binary format executing at near-native speed in browsers and edge runtimes.

## VantaDB context

`vantadb-wasm` binding target; crash model in `docs/wasm/CRASH_MODEL.md`, API in `docs/api/WASM_API.md`.
