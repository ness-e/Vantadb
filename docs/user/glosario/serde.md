# Serde

## Definition

De-facto Rust framework deriving `Serialize`/`Deserialize` for structured data.

## VantaDB context

Serialization pair `[[serde]]` + `[[postcard]]`: JSON at API boundaries, binary on disk (see `[[serialization]]`).
